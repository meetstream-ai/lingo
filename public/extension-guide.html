Read captions over your meeting.

The Chrome extension places translated text over the meeting page, visible only to you. It works in Chrome with Google Meet, Zoom web, and Microsoft Teams web. Desktop Zoom and Teams apps need the web captions window instead.

Install and connect once

  1. Download the extension ZIP and extract it. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extracted extension folder. Pin Lingo to the toolbar. Existing installations need Reload after updating the files.

  2. For your own workspace, download the complete starter kit, extract it, install Node.js 24 or newer, and run npm start. It creates a private .env and installs missing dependencies. Configure MeetStream, Google Translate (or another text provider), a workspace password and an ngrok token in .env or Connections. Speech credentials belong in the corresponding MeetStream workspace. No provider credentials are bundled. Stop with npm stop or Ctrl+C in its original terminal.

  3. Open your signed-in workspace. In the extension enter its URL and click Connect open workspace. This authorizes meeting creation, selection and stopping for 24 hours. HTTPS hosts require Chrome's permission for that workspace hostname. You can revoke all extension connections from Connections.

  4. Join any Google Meet, Zoom web or Teams meeting. Open the extension in that tab. The meeting invitation fills automatically; Teams may require its original invitation URL. Choose the spoken and caption languages and press Start captions. Deepgram needs a fixed source language; AssemblyAI live currently needs English. Admit the visible bot. Every tab keeps its own captions and language.

  5. Show or move the overlay, choose Listen, and open Settings to change its width, text size or position. The Move handle can be dragged anywhere or moved with arrow keys. Recent meetings can be selected on their matching meeting tab. Starting the same active room reuses its existing bot.

  6. Press End recording and open summary to stop the bot and open the website. Post-call processing takes time. The website provides recordings, attributed transcripts, multilingual summaries, notebooks and exports. Manual meeting-scoped connection remains available for samples or read-only overlay access.

What happens to the audio and text?

The extension does not capture your microphone, scrape meeting captions, or transmit meeting-page content. A visible MeetStream bot receives the meeting audio; your selected speech provider recognizes it and sends speaker-attributed turns to this app. The server translates each turn, stores the original and translation, and sends it to the captions web view.

The extension polls this app for the latest live captions every 1.5 seconds, so it adds up to approximately 1.5 seconds plus network time to the server's caption availability. Speech recognition, translation, and network delays come before that. A precise speech-to-caption measurement still requires a synchronized real-call test.

Workspace authorization can list meetings and create or stop bots. Only the extension popup can use it. Each overlay receives a separate meeting-scoped grant; one meeting page cannot select another meeting or read provider credentials. Grants stay in trusted extension storage and expire after 24 hours. Disconnect clears local access; Connections → Revoke removes all server grants.

Listen to translated captions

Listen is optional. Cloud audio uses Google Cloud Text-to-Speech and your workspace speech key (or the existing Google Translation key). Enable that API, billing and the key’s Text-to-Speech permission. If cloud speech is unavailable, the app tries an installed device voice for the selected language. It reports a missing voice rather than speaking in another language. Speech support varies by provider and device and does not cover every text-translation language.

Enable Google Text-to-Speech

  1. Select the Google Cloud project containing your key. Enable billing, then enable Cloud Text-to-Speech API.

  2. In APIs & Services → Credentials, edit your API key. Under API restrictions, allow Cloud Text-to-Speech API. If sharing the translation key, keep Cloud Translation API allowed too. Server requests need a server-compatible key restriction, rather than browser HTTP referrers.

  3. Save the key in Connections → Google speech, or set GOOGLE_TTS_API_KEY in private .env and restart. Test the connection. An API_KEY_SERVICE_BLOCKED error means the key still excludes the service.

  4. Choose a ready translated caption or summary and press Listen. Device voices are a fallback when cloud audio is unavailable. To use Hindi or Tamil offline, install the matching voice in your operating system's speech settings.

Google setup reference

Supported meeting links

Google Meet supports both the invitation link and its /meet/ call URL. Zoom supports numeric invitations and web join/start links. Teams supports modern numeric and encoded meetup-join invitations, including the teams.cloud.microsoft web host. A homepage or generic app/chat URL cannot identify a room. For a Zoom personal /my/ link, copy the numeric invitation after joining. Reload the extension from the updated folder and check the version in its header.

Provider choices

DeepL is an optional text translator configured in Connections with its API Free or Pro key. Its verified adapter catalog is narrower; use Google, Azure or JigsawStack for Hindi and Tamil targets. A provider is selectable only after credentials are saved and its last check has not failed.

JigsawStack text translation supports 162 languages (163 codes). Google and Azure have their own catalogs. Choose up to eight output languages per meeting; adding a language translates saved turns and future captions and may incur provider charges.

AssemblyAI speech keys, JigsawStack speech keys, and Deepgram keys are managed in the MeetStream account associated with your API key. A separately configured JigsawStack text key powers this app's translations. MeetStream currently documents AssemblyAI live as English-only and JigsawStack live as Google Meet-only. Unsupported combinations are rejected before the bot is queued.

If no captions appear

Check the workspace's meeting status and error message. A failed bot, denied admission, missing provider key, or failed translation cannot produce an overlay. Keep the server and its public callback URL running. Open the extension on the meeting tab and start or select that meeting. If a connection expires, use Connect open workspace again. Revoke all extension connections when access should end.
